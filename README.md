# 🌸 梦之韵官方github项目
梦之韵原班团队运营的服务器，猫猫园的后续项目

> 梦之韵团队官方网站 — 基于 PHP 8.3 + Java + CSS3 + JavaScript 构建，展示团队介绍、作品与动态资讯。

## ✨ 功能特性

- 🏠 首页 / 团队简介 / 作品展示 / 新闻动态
- 🎨 响应式布局（PC & 移动端）
- ⚡ PHP 后端渲染，轻量无框架依赖
- 🔐 简易后台登录 & 内容管理（如有）
- 📁 静态资源分离，便于维护
